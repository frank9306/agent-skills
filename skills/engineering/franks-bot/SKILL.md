# Windows 桌面操作与验收

## 工具选择

真实浏览器网页测试统一使用 `ego-browser`，包括打开页面、交互、截图和验收回读。读取当前环境的 `ego-browser` Skill，按说明运行 `ego-browser skill`，以当前安装版本的指南为准。命令不在 PATH 时，使用已核实的 ego lite 安装目录下的 `ego-browser.exe`。

同一任务包含桌面和网页时，Windows 原生窗口步骤用 franks-bot，网页步骤用 `ego-browser`，汇总两边的断言和证据。桌面浮层要求适用于 franks-bot 的桌面操作。浏览器步骤沿用 `ego-browser` 的会话和反馈机制。若 `ego-browser` 无法运行，按其 Skill 排查并报告仍无法完成的浏览器验收。

## 强制规则：状态栏和鼠标光圈全程显示

使用本技能操作界面时，同一任务必须从首次界面操作前到整场结束持续显示同一个状态栏和跟随真实鼠标指针的蓝色光圈。切换屏幕、软件或窗口，打开弹窗、最小化、等待、截图、读取和分批执行时均适用。状态栏跟随当前目标窗口所在屏幕，鼠标光圈始终跟随实际指针位置。子步骤、子用例和工具调用结束都不能提前关闭浮层。

首次界面操作前按[会话执行参考](references/session.md)启动并核验任务级浮层。整场复用同一浮层、事件流和任务计时，切换目标时在同一会话中重新绑定。禁止使用临时单步浮层拼接任务、关闭反馈或切换到无法维持反馈的工具。发现任一显示丢失或无法核验时，立即暂停界面操作，恢复并核验后才能继续。无法恢复时结束任务并报告中断。

## 定位与回读

目标尚未打开时，先用已核实的当前窗口启动浮层，再启动目标软件。新窗口出现后重新绑定。先按可执行路径、PID 和窗口句柄绑定原生窗口。单步原生操作、滚动拖动和托盘调试见 [Windows 执行参考](references/windows-desktop.md)。

使用结构化定位执行动作。目标缺失时按会话参考降级，有候选才调用 Jev。视觉坐标来自本轮截图。如果动作已发出，回读确认再决定是否继续。可信的截图、控件值和状态变化是验收依据。报告操作、技术、耗时、断言结果和证据。
