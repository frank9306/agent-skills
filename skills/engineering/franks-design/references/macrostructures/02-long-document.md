## 02 · 长文档

读起来就像一份备忘录、一封信或一篇日记。没有营销结构。带有内联章节标题的连续散文。该页面是有关该产品的文献。

- **标题：**与正文一致；章节标题从段落流中以简短的粗体短语出现。
- **正文：** 单栏，行高 1.65 或以上，尺寸 60 至 65ch。
- **分隔线：**负空间；间隙是分隔线；至多一个居中的装饰物以示强调。
- **按钮：**段落内的印刷链接，带有动词，而不是单独的块。这是折叠的一个可见动作 (44b)。
- **图像：** 内联，尺寸适合尺寸；永远不会满血。
- **揭示：**无。该页面就在那里。

获取案例研究、创始人帖子、使命页面以及销售具有哲学意义的产品。提示说“讲一个故事”，而不是“列出功能”。

避免在需要采取一项决定性行动的情况下进行。长文档将其操作隐藏在句子中，这对于事务性页面来说是错误的。

标题：[`../craft.md`](../craft.md) § 7，第 3 项的内联引入。

```html
<article class="prose">
  <p class="lede">…</p>
  <h2 class="inline">A small heading.</h2>
  <p>… <a href="#prices">See the prices</a> …</p>
</article>
```

```css
.prose { max-width: 65ch; }
.prose h2.inline { display: inline; font: inherit; font-weight: 700; letter-spacing: normal; }
.prose h2.inline + p { display: inline; }
```

**开头行示例**（模仿具体性，而不是措辞）：
> *“星期六，早上 6:14。面团在午夜进入。”* 以时间戳打开；该品牌将自己介绍为一天中的一个时刻（枫树街面包）。
> *“为那些仍然读到最后的人提供的月刊。”* 指出节奏和读者。
> *“我们建造一件事，我们已经建造它九年了。”* 一个动词，一个计数，没有主张。
