# 微交互

当页面具有有状态 UI 时加载。 `craft.md` § 5 拥有期限、三项宽松和禁令； `gates.md` 拥有告诉 (10, 11, 12, 15, 16, 17, 18, 26, 27, 62)；主题的 Motion 部分决定移动量。该文件拥有食谱，并且不重复它们。

## 原则

- **动作要么有工作，要么被削减。**每一个动画都会澄清、指导或确认。问问如果它是即时的，会失去什么；如果没有，请将其删除。
- **静默成功。** 当用户可以看到结果时，无需吐司。 Toasts 用于失败和页面无法显示的效果。
- **乐观有回滚。** 立即更新接口，将请求发送到后面，并以失败时重试的方式回滚。
- **减少动态效果是一种状态，而不是事后的想法。** 下面的每个配方都将其命名为：空间运动折叠为 150ms 不透明度交叉淡入淡出，功能状态仍然会发生变化。
- **键盘优先。** 每个悬停可供性都有一个焦点等效项；没有什么是只能悬停的。
- **每页最多三个基元**（显示、悬停信号、一个功能循环（例如选取框或计数器）计为 3）。主题的特征仍然是功能状态变化。

## 食谱

持续时间为 `--dur-micro` 120ms、`--dur-short` 220ms 和 `--dur-long` 420ms；输入 `--ease-out`，在输入的 60% 到 75% 处退出 `--ease-in`，切换 `--ease-in-out`。弹簧仅在俏皮主题、主控件和一个角色时刻 (12) 上声明的弹簧姿势下出现。

**按下按钮。** 悬停是一个信号，一种颜色变化；按下是 1px 下降，指针向上时释放。对焦环从不动画。

```css
.btn { transition: background-color var(--dur-short) var(--ease-out), transform var(--dur-micro) var(--ease-out); }
.btn:hover { background: var(--color-paper-3); }
.btn:active { transform: translateY(1px); }
```

**输入焦点。** 轮廓立即出现，插入输入；边框可能会加深一步，但其宽度不会改变 (39a)。标签静止地位于字段上方，从不移动：浮动标签最初是作为占位符，这就是说明。

**验证。** 一旦触摸该字段，首先进行模糊处理，然后对每个输入进行处理；永远不会在第一次击键时。辅助行替换同一保留行 (F14) 中的错误：什么损坏了，为什么，该怎么办。场上的 `aria-invalid` 和 `aria-describedby`。

**干杯。** 失败和隐形效果仅限 (16)。一个角落，最新的以一种方式推动堆栈，没有其他东西重新定位。在 `--dur-long` 上，停留 4 到 6 秒，输出为 65%；悬停和聚焦时自动关闭暂停；错误 Toast 会执行一次重试操作，并且不会自行消失。

**模态。** `<dialog>` 打开，其后面的页面上带有 `showModal()`、`inert`。背景淡入淡出，面板比例在 `--dur-long` `--ease-out` 上为 0.96 至 1； `--ease-in` 的收盘价约为 65%。第一个焦点转到第一个交互元素，而不是关闭按钮。减少动态效果：150ms 交叉淡入淡出。

**菜单。** Popover API（免费的轻关闭、转义和堆叠）、在边缘的 16px 内翻转的 CSS 锚点定位。开盘价高于 `--dur-short` `--ease-out`，收盘价为 `--ease-in` 的 65%；当数量为八个或更少时，项目可能会错开 30ms。

**工具提示。** 悬停延迟 800 至 1000ms，聚焦延迟 0 (17)； `--dur-micro` 的不透明度。当指针移动到它上面时它会停留并离开 Escape (WCAG 1.4.13)。

**制表符更改。** 指示器在 `--dur-short` 上移动 `transform`（在 x 轴上平移和缩放，而不是 `width`）；传出面板在 `--dur-micro` 处淡出，传入面板随之淡出。更改高度的面板会将 `grid-template-rows: 0fr` 动画化为 `1fr`，而不是 `height`。

**数字刻度。** 仅实际数字 (46a)。加载数据时，从上一个值（首次加载时为零）开始计数超过 400 到 800ms，并将 `--ease-out` 应用于该值，格式为 `Intl.NumberFormat`。仅公布最终值（`aria-live="polite"`）。减少动态效果：一次的最终值。

**复制到剪贴板。** 标签切换为*已复制*，持续 2.5 秒；没有吐司，标签就是反馈。

```js
btn.addEventListener("click", async () => {
  await navigator.clipboard.writeText(value);
  btn.dataset.state = "copied";
  setTimeout(() => delete btn.dataset.state, 2500);
});
```

**拖动以重新排序。** 手柄出现在悬停和焦点上；光标为`grab`，然后为`grabbing`；不透明度为 50% 的重影跟随指针，1px 重音线标记放置目标。释放卡扣位于 `--dur-short` `--ease-out` 上，无弹簧。箭头键对焦点行重新排序； `aria-live`宣布此举。

**乐观更新。** 行立即更改，请求在其后面运行。成功没什么可说的。失败会将行回滚到​​ `--dur-short` 并引发“再试一次”的提示，该提示将一直保留到执行操作为止。

```js
const prev = item.done;
item.done = !prev; render();
try { await api.update(item); }
catch { item.done = prev; render(); toast({ tone: "error", message: "Could not save.", action: { label: "Try again", run: retry } }); }
```

**边输入边搜索。** 反跳 250ms；等待的时候，场上传来安静的信号（边界进一步加深）。 `<mark>` 中的比赛。一旦去抖稳定，就宣布结果计数，而不是每次击键。

**命令面板。** 在 ⌘K 或 `/` 上立即打开；输入始终保持焦点。箭头键移动突出显示，该突出显示在 `--dur-micro` 上滑动 `transform`；这些行本身永远不会移动。 Enter 选择，Escape 关闭。行可能会在首次打开时淡入，而不会在过滤时淡入。

**页面加载显示。** 一个精心策划的入口，根据 `craft.md` § 5：按 DOM 顺序交错，总共 0.4 到 0.8 秒，IntersectionObserver 而不是滚动侦听器，一次。静态主题会跳过它，这是正确的。

## 动作角色

每个系统都会声明一个：其运动部分中的目录主题，其自己的样式表中的自定义页面。同样的压力在严格的系统中比在平静的系统中声音更大。

| 特点 | 持续时间范围 | 感觉就像 |
| --- | --- | --- |
| **仍然** | 没有任何 | 打印。什么都没有动；插入符号可能会在键入的命令内闪烁，四到五拍然后稳定，永远不会单独出现。 |
| **严重** | 0.7～0.75倍 | 快速而果断；卡入到位；任何地方都没有春天。 |
| **轻快** | 0.85～0.9倍 | 技术和功能：仪表板。 |
| **冷静的** | 1.0至1.3倍 | 内敛到大方，`--ease-out` 尽显温柔。 |

大多数页面的动作太多，而不是太少。静态答案通常是正确的。
