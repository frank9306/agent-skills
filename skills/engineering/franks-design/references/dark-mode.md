# 深色模式：奇偶校验，永不反转

仅当用户请求两种模式（“深色模式”、“浅色和深色”）或预检找到要尊重的现有模式系统时才加载。深色主题（午夜、黄昏、窑炉）不是双模式页面；该文件适用于从一个令牌系统传送两种模式的页面。切勿在无提示的情况下发出双模式。

## 立场

深色模式是同一系统的第二种同样设计的渲染：不是 `filter: invert()`，不是“翻转灰色”。每个token都是通过recipe重新派生的；每个对比目标在两种模式下都保持相同；锚色调永远不会移动。如果令牌在重新派生后无法进行对比配对，请修复派生，而不是要求。

## 设计令牌重新派生（每个设计令牌，来自光值）

| 设计令牌 | 暗推导 |
| --- | --- |
| `--color-paper` | L 12-18%，锚色 (chroma 0.008-0.015)。从来没有`#000`。 |
| `--color-paper-2/3` | 高度更亮：纸张上方每升高 3% L（亮模式会变暗；暗模式会变亮）。 |
| `--color-ink` | L 92-96%，锚色。从来没有`#fff`。 |
| `--color-ink-2` / 静音 / 中性 | 重新调整新纸张和墨水之间的 L 步距，使印刷深度均匀；保留每一个色度色调。 |
| `--color-rule` | L~26-34%；发际线必须在黑暗的地面上生存 (check against paper-2, not just paper)。 |
| `--color-accent` | 色度 -0.02 至 -0.04，L +5-10%（饱和光模式强调黑暗中的眩光）。 |
| `--color-accent-ink` | 重新验证：>= 4.5:1 正文 / 3:1 大新重音填充。 |
| `--color-focus` | 遵循重音推导；与两篇论文的环形对比度为 3:1 或以上。 |
| 色调 | 切勿在任何令牌上在模式之间移动。 |

加一非令牌招式：在黑暗中将身体 `font-weight` 减少 50 个单位 (400 to 350)；深色文本在视觉上看起来更重。

## 排放

`tokens.css` 按原样携带灯块，然后添加了两个：

```css
[data-mode="dark"] { /* only the tokens that move, re-derived per the table */ }

@media (prefers-color-scheme: dark) {
  :root:not([data-mode]) { /* the same overrides, for OS-preference auto mode */ }
}
```

`[data-mode]` 属性通过构造胜过媒体查询（媒体块仅在未设置显式模式时适用）。切换：一键设置 `document.documentElement.dataset.mode`，持续到 `localStorage`，在第一次绘制 4 行内联脚本之前读取，这样页面就不会闪烁错误的模式。 `color-scheme: light dark` 在 `:root` 上，因此表单控件和滚动条跟随。

## 黑暗纪律（改变的规则）

- **阴影关闭。** 高度为亮度（+3% 阶梯）或嵌入发丝环（`box-shadow: inset 0 0 0 1px var(--color-rule)`）。黑暗中的阴影读作辉光；发光仅在大气类型剥离下才合法（`genres/atmospheric.md` §此处允许：两个固定的绽放），这是一种主题行为，而不是模式行为。
- **卡片比画布轻。** `paper-2` 在 `paper` 上，始终；一张比地面颜色更深的卡片读作一个洞。
- **一种标题颜色。** 标题全部运行 `--color-ink`；每个标题的颜色变化适用于黑暗中的浅色片段。
- **图像。** 切勿在光栅图像上使用 CSS `invert`/`brightness`。选择能在深色背景上保持的照片（图书馆的 `dark` 和 `mid` 色调），或在 `paper-2` 槽中放置一张浅色照片，这样它看起来就像一张盘子。主题的多重板（双色调处理、纹理）需要它们的暗模式对； texture.md 记录了纹理的覆盖交换。
- **图表。** 标记重新派生为重音（色度向下，L 向上）；来自黑暗`--color-rule`的网格线；请参阅 data-viz.md § 深色。

## 确认

两种模式都运行完整的门扫描：在两种模式下的每个配对上对比门 40-41（渲染层仅看到默认模式；以数字方式检查暗配对），门 7a 和 7b（无纯黑或白）也绑定在暗块上，并且标记记录 `modes: light+dark`，以便日志知道。
