# 产品演示录制

先确认演示目标、受众和功能顺序，沿用用户已给的时长与文案要求。用演示数据编排短场景：每段操作完成并断言成功后，再讲解当前画面。旁白默认 `zh-CN-YunyangNeural`（云扬），字幕采用同一语音的句子时间边界；用户点名其他声音时覆盖默认值。

执行前读取 [计划与运行](references/plan.md)，按 franks-bot 的当前观察绑定真实窗口及操作目标。把演示流程写为计划，使用本技能脚本完成配音、录制、同步与合成；全部场景复用同一个 bot 连接。需要的桌面能力由 franks-bot 提供，本技能不维护另一套定位逻辑。

录制范围是明确绑定的 Windows 窗口。清除或避开私人内容，关闭会泄露数据的弹窗；在线配音只发送经确认可用的讲解文案。遇到操作断言失败、录制失败或语音过长，保留失败材料并停止，修正计划后从新的目录开始，不把失败片段当成成功演示。

交付前核查 `verification.json`、动作日志和 `timeline.json`，抽看每段旁白开始时的画面及字幕、检查音轨可听；技术验证不等于用户认可声音听感。交付 `demo.mp4`，需要编辑时同时提供 SRT、旁白 WAV 和时间轴。明确演示fixture与真实产品的区别，不把模拟页面称为产品实录。
